# Contributing

Help make IT study material clearer, more accurate and easier to practice.

## Report a correction

Include the handbook name, page number, objective, current explanation, suggested correction and a primary reference. Distinguish an incorrect fact from a teaching preference. For layout problems, describe the affected page and device.

## Propose a change

Open an issue or a focused pull request. Explain the learning problem, your proposed change and how a learner can verify it. Keep terminology consistent with the identified exam version.

Do not submit real exam questions, confidential employer material, credentials, private logs or content you do not have permission to contribute. Use synthetic data in examples.

Maintainer review is required before changes become part of the published collection. Suggest content corrections in Markdown rather than replacing the handbook with an unexplained binary edit.
